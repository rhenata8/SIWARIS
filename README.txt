SIWARIS – Prototype Interaktif
Kelurahan Sumbertaman

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder SIWARIS_Prototype.
3. Klik dua kali file index.html.
4. Prototype akan terbuka di Chrome/Edge.
5. Semua menu dapat diklik.
6. Fitur "Tambah SKW" dapat digunakan untuk menambahkan data contoh selama browser terbuka.

CATATAN:
Ini adalah prototype front-end interaktif, bukan sistem produksi. Data tersimpan hanya selama halaman/browser berjalan dan belum terhubung ke database/server.
Jangan memasukkan NIK atau dokumen pribadi nyata.

Tahap produksi berikutnya dapat dibuat dengan login, database MySQL, penyimpanan PDF, QR verifikasi, audit log, backup, dan hak akses pengguna.
